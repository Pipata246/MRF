# MRF — Make Russia Free

Музыкальный стриминговый сервис на чистом HTML, CSS и Vanilla JavaScript.

## Структура проекта

```
MRF/
├── public/
│   ├── index.html          # Главная страница
│   ├── search.html         # Поиск
│   ├── charts.html         # Чарты
│   ├── library.html        # Библиотека
│   ├── liked.html          # Любимые треки
│   ├── playlists.html      # Плейлисты
│   ├── albums.html         # Альбомы
│   ├── artists.html        # Исполнители
│   ├── profile.html        # Профиль и настройки
│   ├── artist.html         # Страница артиста
│   ├── album.html          # Страница альбома
│   ├── playlist.html       # Страница плейлиста
│   ├── track.html          # Страница трека
│   ├── app.js              # Основная логика приложения
│   ├── shared.js           # Общие компоненты (sidebar, player, topbar)
│   ├── mock.js             # Моковые данные и Store
│   ├── style.css           # Стили
│   └── img/                # Изображения
├── package.json
├── vercel.json
└── README.md
```

## Запуск локально

```bash
npm run dev
```

Приложение откроется на `http://localhost:3000`

## Основные функции

### ✅ Реализовано

- **Многостраничная архитектура** — каждый раздел имеет отдельный HTML-файл
- **Единый layout** — sidebar, topbar, player сохраняются между переходами
- **Библиотека** — избранные треки, плейлисты, исполнители
- **Управление плейлистами** — создание, редактирование, удаление
- **Контекстные меню** — добавление в плейлист, избранное
- **Поиск** — треки, артисты, альбомы с фильтрацией
- **Чарты** — мировые и региональные топы
- **Профиль** — настройки интерфейса, воспроизведения, уведомлений
- **localStorage** — сохранение избранного, плейлистов, профиля
- **Страницы артистов, альбомов, плейлистов** — детальная информация

## Технологии

- HTML5
- CSS3 (CSS Variables, Grid, Flexbox)
- Vanilla JavaScript (ES6+)
- localStorage для хранения данных
- Deezer API для получения музыки (в демо-режиме)

- **Цветовая схема:**

## Storage (localStorage)

- `mrf_favs` — избранные треки
- `mrf_playlists` — пользовательские плейлисты
- `mrf_followed` — подписки на артистов
- `mrf_recent` — недавно прослушанное
- `mrf_profile` — данные профиля
- `mrf_settings` — настройки приложения
- `mrf_search_history` — история поиска
- `mrf_queue` — очередь воспроизведения
- `mrf_player` — состояние плеера
- `mrf_sidebar_collapsed` — состояние sidebar

## Развёртывание

Проект настроен для деплоя на Vercel:

```bash
vercel deploy
```

Настройки в `vercel.json`:
- Статические файлы из папки `public/`
- Все запросы перенаправляются в `/public/`
